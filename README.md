## Tech stack

- **Vue 3** (`<script setup>`), **Vue Router**
- **SCSS** with a small mixin library for grid/flex layouts and breakpoints
- **Vite**
- Deployed to **GitHub Pages** via GitHub Actions (`.github/workflows/static.yml`), with a `404.html` fallback so client-side routes survive a page refresh

## Running locally

```bash
npm install
npm run dev
```
